# Usos de marca

## 1. APK / launcher de Android
- Usar `02_APP_ASSETS/icons/icon-1024.png` como base principal.
- Para Android adaptive icon usar `02_APP_ASSETS/adaptive/adaptive-foreground-1024.png`.
- Color de fondo recomendado: `#0F1210`.

## 2. Dentro de la app
- Header principal: `01_LOGO/logo-horizontal-transparente.png`.
- Login / onboarding: `03_SPLASH/splash-dark-1080x1920.png` o `splash-light-1080x1920.png` como referencia visual.
- Estados de carga: `04_GIFS/loading-dark.gif` o `04_GIFS/loading-light.gif`.
- Notificaciones / íconos simples: `02_APP_ASSETS/notifications/notification-96.png`.

## 3. Cómo debe verse en la app
- Fondo oscuro recomendado para pantallas principales: `#0F1210`.
- Acento verde lima: `#A7F55B`.
- El logo horizontal se usa en zonas con suficiente ancho.
- El emblema solo se usa cuando el espacio es reducido: tabs, botón flotante, splash minimal o avatar.

## 4. Para vender/promocionar la app
- Banner horizontal: `05_MARKETING/feature-graphic-1774x887.png`.
- Banner compacto tipo store: `05_MARKETING/feature-graphic-1024x512.png`.
- Publicación cuadrada/redes: `05_MARKETING/social-square-1254x1254.png`.
- La guía de marca `01_LOGO/guia-visual-de-marca.png` sirve para presentar identidad a socios, equipo o stakeholders.

## 5. Tamaños mínimos sugeridos
- Ícono app digital: 24 px mínimo absoluto.
- Ícono recomendado en interfaz: 32 px o más.
- Logo horizontal digital: 80 px mínimo de ancho.
